# LogPapa (로그 제조기 Pro 2)

AI 롤플레이 채팅 로그를 인라인 CSS 카드로 꾸며 커뮤니티에 그대로 붙여넣고,
작품별로 모아 웹소설처럼 읽는 도구. **웹**(https://logpapa.web.app) + **데스크탑**(Electron) 둘 다 제공.
